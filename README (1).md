# Suppression and Selective Allocation of Irreversibility in a Neural Connectome

Code for reproducing the data figures of

> G. Kim, J. Eum and H. W. Kim, *Suppression and selective allocation of
> irreversibility in a neural connectome.*
> Preprint: [arXiv:XXXX.XXXXX](https://arxiv.org/abs/XXXX.XXXXX)

## What this is about

A connectome fixes which neurons talk to which, and with what sign. Treating the
wiring as the coupling matrix of a linear stochastic network turns it into a
non-equilibrium steady state, and the time-irreversible part of that steady
state has a single scalar measure, the entropy-production capacity σ. This work
asks how much irreversibility the *C. elegans* wiring produces and where it goes.

Two things follow. First, the real connectome produces markedly less σ than
rewired networks that keep its degrees, its feed-forward hierarchy or its exact
synaptic strengths, and this suppression grows over development. Second, the
irreversibility that remains is not spread evenly: it concentrates on a few
integration and command interneurons (RIA, AVA) and aligns with specific
behavioural circuits beyond what the strength sequence alone would predict.

## Repository contents

```
code/
  connectome.py        data loading, σ and σ_i, null models, circulation modes
  compute.py           all computations -> results/*.json
  make_figures.py      Figures 1(b), 2, 3, 4, S1, S2, S3 from results/*.json
  check_results.py     key numbers vs. the reference run -> results/summary.csv

results/
  fig1b.json           σ vs directed fraction λ
  fig2.json            σ of 4 x 1000 null networks, suppression, trophic levels
  fig3.json            F0 and σ of 1000 degree-preserving nulls
  fig4ab.json          σ_i, circulation participation c_i, circuit alignment,
                       Fig S1 residuals and mode-by-circuit z, Tables SVIII, SIX
  snull.json           circuit alignment on 1000 strength-preserving nulls
  dev.json             eight developmental stages: suppression, 95% CI, ranks
  swapconv.json        swap-budget check for the strength null (SI S2)
  summary.csv          every reported number next to the reference value

figures/               output of make_figures.py
```

`results/summary.csv` is the quickest way in: it lists every reported number,
so the results can be checked without running anything. The JSON files hold
the full null distributions behind each figure.

## Running the code

```
pip install -r requirements.txt
python code/compute.py          # all parts; or e.g. `python code/compute.py fig2 dev`
python code/make_figures.py
python code/check_results.py
```

Both connectomes are read through the OpenWorm ConnectomeToolbox (`cect`),
which ships the spreadsheets, so no data files have to be downloaded by hand
(see "Data" below).

No special hardware is needed. `compute.py` takes about 45 minutes on a single
desktop CPU core and about 1.5 hours on a standard Google Colab CPU runtime; almost all of it goes into the null ensembles (`fig2`, `dev`,
`swapconv`, `snull`). Each part writes its own JSON file, has its own seed and
can be run separately or in parallel processes.

The four scripts can also be dropped into a single folder and run from there;
`results/` and `figures/` are then created next to them.

## Scope

The code reproduces the main-text figures and the parts of the Supplemental
Material that use the primary Cook 2019 network and the Witvliet series:
Figs. 1(b), 2, 3, 4, S1, Tables S1, S6, S8, S9 and the strength-null
swap-budget check of Sec. "Construction and adequacy of the strength-preserving
null". The remaining supplementary analyses — the sign ensemble, the model
variations of Table S3, the saturating-gain test, the other reconstructions of
Tables S4, S5 and S7, the label-free recovery and the leave-one-out control —
use the same routines in `connectome.py` and are available from the
corresponding author on request.

## Model and settings

| item | setting |
| --- | --- |
| neurons | 286 somatic neurons of the adult hermaphrodite (Cook et al. 2019), after removing muscles, lower-case nodes, pharyngeal neurons and glia |
| coupling | W = Aᵀ·diag(s) + G; Dale signs s = −1 for 26 GABAergic neurons |
| drift | A = I − W · 0.8 / max Re λ(W); noise B = I |
| σ | Tr[Mᵀ B⁻¹ M C], M = A − B C⁻¹, A C + C Aᵀ = 2B |
| σ_i | [B^−1/2 M C Mᵀ B^−1/2]_ii = Σ_j G²_ij, non-negative and summing to σ |
| F0 | weighted trophic incoherence, SI Eq. (S2) |
| nulls | chemical double-edge swaps; gap junctions and signs fixed; 1 x edge count successful swaps (10 x for the developmental stages) |
| samples | 1000 nulls per ensemble; 2000 permutations per alignment z; 2000 bootstrap resamples |

## Reproducibility

Random seeds are fixed, so the published numbers come back exactly:

| quantity | value |
| --- | --- |
| σ of the connectome | 0.16568 |
| Fig. 2, suppression vs degree / hierarchy / strength / strength+hierarchy nulls | 20.8 / 21.8 / 13.3 / 12.1 % |
| Fig. 3, F0 connectome vs degree nulls | 0.497 vs 0.670 |
| Fig. 4(b), excess alignment over the strength null, Backward / Nocicept | +1.15 / +1.31 |
| Fig. 4(c), suppression at stage 1 vs stage 8 | 13.0 → 72.7 % |

`python code/check_results.py` compares 58 quantities with this reference run.
They agree to all printed digits across machines; σ itself can differ in the
15th significant digit because of floating-point differences between LAPACK
builds.

## Data

No connectome data are redistributed in this repository. Both datasets are read
at run time through the OpenWorm C. elegans Connectome Toolbox
(https://openworm.org/ConnectomeToolbox/, Python package `cect`), which ships
the original data files and applies its own cell-name conventions:

* Cook, S. J. *et al.* Whole-animal connectomes of both *Caenorhabditis elegans*
  sexes. *Nature* **571**, 63–71 (2019) — Toolbox dataset "Cook et al. 2019
  Herm", read with `Cook2019DataReader` from
  `SI 5 Connectome adjacency matrices, corrected July 2020.xlsx`.
* Witvliet, D. *et al.* Connectomes across development reveal principles of brain
  maturation. *Nature* **596**, 257–261 (2021) — Toolbox datasets
  "Witvliet et al. 2021 1 (L1)" … "8 (adult)".

The published results were produced with `cect` 0.3.4 installed from PyPI.
To read the Witvliet files from a local folder instead, set `LOCAL_DATA` at the
top of `code/compute.py`.
